# QR Code Redirect

A tiny GitHub Pages site that instantly redirects visitors to whatever website
you choose. Make a **QR code that points at this page's URL** — then you can
change where that QR code ultimately sends people *without ever reprinting the
QR code*.

## The QR code should point to

```
https://sanil-sharma.github.io/QR-code-redirect/
```

## How to change the destination

1. Open `index.html`.
2. Change the `DESTINATION` URL near the top.
3. Commit and push:
   ```
   git commit -am "Update redirect destination"
   git push
   ```
4. Within a minute or so, the QR code sends people to the new site.
